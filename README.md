Oil Prices vs USD/NGN Exchange Rate Analysis (2014–2024)

Overview
This project analyzes the relationship between global oil prices and the Nigerian naira exchange rate.

Dataset
- Brent Crude Oil Prices
- USD/NGN Exchange Rate

Methodology
1. Data cleaning
2. Return calculation
3. Exploratory data analysis
4. Correlation analysis
5. Lag analysis
6. Regression modeling

Tools
Python, pandas, matplotlib, statsmodels, yfinance

Key Finding
The correlation between oil price returns and USD/NGN returns is weak, suggesting exchange rate movements may be influenced more by policy and structural economic factors.
